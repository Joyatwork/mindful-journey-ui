🔧 Configuration Google OAuth

📋 Vous avez déjà créé des clients OAuth !
Suivez les étapes ci-dessous pour configurer votre application.

📋 Étape 1 : Récupérer votre Client ID

Dans Google Cloud Console :

  1. Cliquez sur l'un de vos "Mindful Journey Laravel Client"
  2. Copiez le Client ID complet (commence par 210024066224-...)
  3. Collez-le dans le champ ci-dessous :

🔧 Étape 2 : Vérifier les URLs autorisées

Assurez-vous que ces URLs sont dans vos "Origines JavaScript autorisées" :

URLs à ajouter :
• http://localhost:8080
• http://127.0.0.1:8080

⚙️ Étape 3 : Mise à jour automatique du fichier .env

Une fois le Client ID saisi, copiez cette ligne dans votre fichier .env :

VITE_GOOGLE_CLIENT_ID=votre_client_id_ici

🔄 Étape 4 : Redémarrer le serveur

Après avoir mis à jour le fichier .env :

# Arrêtez le serveur (Ctrl+C dans le terminal) # Puis redémarrez : npm run dev

🧪 Étape 5 : Tester la connexion Gmail

Une fois configuré, vous pourrez :
✅ Cliquer sur "Se connecter avec Google"
✅ Utiliser votre vraie adresse Gmail
✅ Être automatiquement connecté à l'application
🚀 Ouvrir l'application
