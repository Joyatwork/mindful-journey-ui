====================================================
🚀 COMMENT UTILISER LE PROJET
====================================================

1. DÉMARRAGE AUTOMATIQUE:
   Exécuter: .\start-project.ps1

2. DÉMARRAGE MANUEL:
   Backend:  cd back-mindful-journey-iu\mindful-journey-back && php artisan serve --host=127.0.0.1 --port=8081
   Frontend: npm run dev

3. URLS D'ACCÈS:
   - Application: http://localhost:8080
   - API:         http://127.0.0.1:8081/api

4. ENDPOINTS DISPONIBLES:
   - POST /api/auth/register     (inscription)
   - POST /api/auth/login        (connexion)
   - GET  /api/auth/user         (profil - avec token)
   - POST /api/auth/logout       (déconnexion - avec token)
   - GET  /api/auth/google       (OAuth Google)

====================================================
📝 PROCHAINES ÉTAPES RECOMMANDÉES

1. 🔐 CONFIGURATION GOOGLE OAUTH (optionnel):

2. 🎨 PERSONNALISATION FRONTEND:
   - Modifier les composants dans src/components/

3. 🔧 DÉVELOPPEMENT BACKEND:
   - Ajouter de nouvelles routes dans routes/api.php
   - Créer des contrôleurs dans app/Http/Controllers/Api/
   - Gérer les données wellness (mood, meditation, etc.)
