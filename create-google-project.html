🔧 Étape 2: Activer l'API Google Identity

1. Dans votre nouveau projet, allez dans :

Menu ☰ → APIs et Services → Bibliothèque

2. Recherchez : "Google Identity Services API"

3. Cliquez dessus et appuyez sur "ACTIVER"

🔍 Rechercher l'API Google Identity

👥 Étape 3: Configurer l'Écran de Consentement

1. Allez dans :

APIs et Services → Écran de consentement OAuth

2. Choisissez "Externe"

3. Remplissez :

Nom de l'application: Mindful Journey E-mail d'assistance utilisateur: alicamara291@gmail.com E-mail de contact du développeur: alicamara291@gmail.com

alicamara291@gmail.com

🔑 Étape 4: Créer les Identifiants OAuth

1. Allez dans :

APIs et Services → Identifiants

2. Cliquez sur "CRÉER DES IDENTIFIANTS" → "ID client OAuth 2.0"

3. Configuration :

Type d'application: Application Web Nom: Mindful Journey Web Client Origines JavaScript autorisées: • http://localhost:8080 • http://127.0.0.1:8080 URI de redirection autorisées: • http://127.0.0.1:8081/api/auth/google/callback

4. Cliquez sur "CRÉER"
